# JANDI → Notion 검색 v3.7

잔디 메시지 상단을 Markdown 표 대신 2줄 요약형으로 변경했습니다.

예:

🔎 Notion 검색 결과

🔍 ISG   ·   20건   ·   일반
📚 447개   ·   🕒 09.19 13:34

1. ISG-SSP 계산기
2. ISG license 갱신
3. ISGAC 1.2.1
...

🌐 전체 결과 보기

검색 방식 표기:
- 일반 검색 → `일반`
- `&` → `AND`
- `|` → `OR`
- 둘 다 사용 → `AND·OR`

기존 447페이지 인덱스는 그대로 사용하므로 재인덱싱이 필요 없습니다.
